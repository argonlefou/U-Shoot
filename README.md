# What it is
Inheriting [DemulShooter](https://github.com/argonlefou/DemulShooter) code and core functionalities, U-Shoot is a kind of swiss-knife / universal tool for a lot of Lightgun games. Main functionalities are :
 - Raw Input support for games not designed to work with anything else than a simple mouse, or a gun controller
 - Native and custom Outputs support, for lamps and force feedback
 - Display rendering patch (multi-screen games, vertical games, etc...) to run on a regular single screen
 - Crosshair removal patch
 - Integrated cursor removal (no more `nomousy.exe`...)
 - Full inputs mapping, with multi-device-input capabilities

For DemulShooter users, the biggest differences will be :
 - No more X86/X64 executables to run, juts one and only program
 - Full Inputs mapping (where DemulShooter only controlled Axes/Trigger/Reload - mostly -)
 - Better hardware device support and multi-device inputs 
 - All-In-One tool embedding all previously created patch/launcher/Mods/etc...

# What is is _NOT_
An emulator, in any way...  
<br>
All games needing an emulator will be executed thanks to the corresponding emulator, U-Shoot will only take controls of Inputs/Outputs.  
Thanks for all the people making this possible (sorry if I forgot someone in the list):
 - [Flycast](https://github.com/flyinghead/flycast)
 - [JConfig](https://jconfig-universe.fandom.com/wiki/JConfig_Universe_Wiki)
 - [LinuxLoader](https://github.com/lindbergh-loader/linuxloader)
 - [PCSX2X6](https://ps2homebrew-arcade.github.io/pcsx2x6/)
 - [RPCS3](https://rpcs3.net/)

For games that can be executed without any emulator (X86/X64 compiled games), U-Shoot will run and patch the games so that they can be displayed, used, an enjoyed in the easiest way possible.
